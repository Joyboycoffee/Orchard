1. Introduction to Orchard

What is this project about?

Orchard is an online store for buying fresh Himalayan apples, apple trees (saplings), rootstocks, and garden tools. It looks and works like a real commercial app, built using simple web technologies without complex database servers!

SLIDE 03

3. The Secret Hero: LocalStorage

What is holding this whole project together?

Instead of using an expensive backend server or database, our project uses LocalStorage—a free digital notebook built inside every web browser!

  • Cart Memory: Items stay in your cart even if you refresh or close the tab.
  • Contact Form: Customer messages are saved directly into the browser notebook.
  • Admin Updates: Adding or editing products in the Admin panel saves to LocalStorage and updates the store immediately.
🗣️ What to say: "The main engine holding this project together is browser LocalStorage. It acts like a digital notebook that remembers our catalog, shopping cart, and messages without needing an external database server."
SLIDE 04

4. Overview of the 5 Pages

What pages exist in Orchard?
1. index.html (Home): Hero section, float animation, Bento highlights grid.
2. products.html (Catalog): Category filter pills, live search bar, product cards.
3. cart.html (Cart): Item table, +/- quantity stepper, coupon box, checkout modal.
4. contact.html (Contact): Nursery address details and inquiry submission form.
5. admin.html (Hidden Admin Suite): Secret password-protected page (admin/admin123) for product CRUD and message inbox.
🗣️ What to say: "There are 5 pages in total. 4 are public storefront pages, and 1 is a hidden secret Admin Panel accessible only by typing /admin.html in the address bar."

5. Quick Summary & Conclusion

Why is this project impressive?
  • ✅ 100% Responsive: Looks amazing on phones, tablets, and desktops.
