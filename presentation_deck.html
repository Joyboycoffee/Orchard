3. Database Architecture & Data Storage

How is data managed in Orchard?

The application utilizes a structured Database System to manage data across 4 primary collections:

  • Products Database: Holds product IDs, names, prices, stock quantities, and image links.
  • Cart Database: Remembers selected items and quantities for active shopping sessions.
  • Inquiries Database: Stores submitted contact form entries with timestamps.
  • Admin Auth Store: Secures credentials for administrative management.
🗣️ Exact Viva Answer to "Which database are you using?":
"We are using a Document-Based JSON Data Store following the NoSQL database model (similar to MongoDB). All entities—Products, Cart Sessions, Customer Inquiries, and Admin Credentials—are structured in JSON document collections."
