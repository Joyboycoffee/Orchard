SLIDE 12 / JSON DEEP DIVE

12. What is JSON? Deep Dive & Benefits

JSON is a lightweight data interchange format structured as labeled key-value pairs inside curly braces { } and arrays inside square brackets [ ].

SLIDE 14 / DATABASE MODEL

14. What Database Architecture is Used?

Document-Based NoSQL Data Store Engine

Orchard utilizes a Document-Based NoSQL Database Model (structured identically to MongoDB document collections). All records are organized as JSON document arrays.

🗣️ Viva Answer to "Which database are you using?":
"We are using a Document-Based JSON Data Store following the NoSQL database architecture model (similar to MongoDB). Products, Cart Sessions, and Messages are structured in JSON document collections."
SLIDE 15 / SQL VS NOSQL

15. SQL vs. NoSQL Comparison

Why NoSQL Fits E-Commerce Best
Feature Relational Database (SQL) NoSQL Document Store (Ours)
Data Structure Rigid tables & columns (like Excel) Flexible JSON documents (like Folders)
Examples MySQL, PostgreSQL MongoDB, Document JSON Store
Schema Flexibility Hard to add new columns dynamically Very easy to add badges/attributes anytime
Query Speed Requires expensive table JOINs Instant document retrieval (< 1ms)
