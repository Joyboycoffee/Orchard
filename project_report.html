ORCHARD E-COMMERCE PLATFORM

Complete Technical Project Report & Specification Document
Academic Submission: BCA 5th Semester | Technology Stack: HTML5, CSS3, ES6+ JS & Database Store

1. Executive Summary

Orchard is an e-commerce web application specifically crafted for high-altitude fresh apples, virus-free clonal rootstocks, saplings, and nursery tools. Designed using a clean 4-tier web architecture, the platform manages products, cart sessions, customer inquiries, and administrative CRUD workflows through a structured Database Layer.

2. Technology Stack

Layer Technology Used Purpose & Implementation
Frontend Structure HTML5 Semantic layout (header, nav, main, section, footer)
Design & Styling CSS3 (Vanilla) CSS Variables, Flexbox, Grid, Glassmorphism, Micro-animations
Logic & Interactivity JavaScript (ES6+) DOM manipulators, state handlers, toast notification system
Database Layer Database Storage Engine Data persistence for Products, Cart Sessions, Messages, and Admin Auth

4. Key Page Functionalities

4.1 Home Page (index.html)

Includes floating hero image animation, call-to-action buttons, trust badges, and an elevated Bento Grid highlights section (*High-Altitude Grown, Cold-Chain Express, Virus-Indexed Stocks, 100% Growth Guarantee*).

4.2 Products Catalog (products.html)

Features real-time category filtering (*All Products, Fresh Apples, Apple Saplings, Rootstocks, Accessories*), instant search bar filtering, and automatic fallback image handling.

4.3 Cart & Checkout (cart.html)

Provides an interactive item table with quantity steppers (+/-), single-click deletion, promo codes (WELCOME10 for 10% OFF), and a complete checkout modal collecting customer details.

4.4 Contact Page (contact.html)

Captures user inquiries and stores them in the customer messages database with exact timestamps.

4.5 Hidden Admin Portal (admin.html)

Accessible only by typing /admin.html. Authenticates with credentials (admin / admin123) and unlocks full Product CRUD (Add/Edit/Delete) and customer message inbox viewing.
